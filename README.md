# Microsoft Windows — a story for Class 4 🪟

A kid-friendly page about Microsoft Windows and its history, made for a Class 4 storytelling assignment.

- **Three levels:** 🟢 Easy (16 pages) · 🟡 Medium (25 pages) · 🔴 Hard (35 pages)
- **📖 Story teller:** a notebook-style script for each page (heading, what to draw, what to say), ready to copy into a notebook.

**Keys:** ← → change page · `S` story script · `F` full screen
